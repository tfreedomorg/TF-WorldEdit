PROJECT OVERVIEW
----------------
Created a new WorldEdit extension plugin that extracts and modernizes the unique
features from TF-WorldEdit (a fork of WorldEdit 6.1.7) for compatibility with
WorldEdit 7.3.x and Minecraft 1.21.x.

FILES CREATED
-------------
1. build.gradle
   - Gradle build configuration
   - Dependencies: WorldEdit 7.3.10, Paper API 1.21.1
   - Shadow plugin for fat JAR creation
   - Guava relocation to avoid conflicts

2. settings.gradle
   - Project name configuration

3. plugin.yml
   - Plugin metadata
   - Dependencies: WorldEdit (required), TotalFreedomMod (optional)
   - API version: 1.21

4. TFWorldEditExtension.java
   - Main plugin class extending JavaPlugin
   - Handles plugin lifecycle (onEnable/onDisable)
   - Waits for WorldEdit to initialize before starting
   - Registers selection listener and limit interceptor

5. WorldEditHandler.java
   - Core utility class ported from TF-WorldEdit
   - Methods:
     * selectionChanged() - Fires SelectionChangedEvent
     * limitChanged() - Fires LimitChangedEvent
     * isSuperAdmin() - Checks TotalFreedomMod super admin status
     * getPlayer() - Converts WorldEdit Player to Bukkit Player
     * getWorld() - Converts WorldEdit World to Bukkit World
   - Handles TotalFreedomMod integration

6. SelectionChangedEvent.java
   - Bukkit event fired when WorldEdit selection changes
   - Implements Cancellable
   - Contains: player, world, minVector, maxVector
   - Ported from TF-WorldEdit

7. LimitChangedEvent.java
   - Bukkit event fired when block change limit is modified
   - Implements Cancellable
   - Contains: player (who changed), target (who limit is for), limit value
   - Ported from TF-WorldEdit

8. SelectionChangeListener.java
   - Monitors WorldEdit selections for changes
   - Polls SessionManager every tick
   - Tracks previous selections to detect changes
   - Fires SelectionChangedEvent when changes detected
   - NEW: Not present in original TF-WorldEdit (was integrated into core)

9. LimitCommandInterceptor.java
   - Intercepts //limit commands
   - Listens to both Bukkit command events and WorldEdit command events
   - Fires LimitChangedEvent before limit is applied
   - NEW: Not present in original TF-WorldEdit (was integrated into core)

10. README.md
    - Complete documentation
    - Installation instructions
    - API usage examples
    - Building instructions

FEATURES IMPLEMENTED
--------------------
1. SelectionChangedEvent
   - Fires when player's WorldEdit selection changes
   - Can be cancelled to prevent selection
   - Provides min/max vectors and world information

2. LimitChangedEvent
   - Fires when //limit command is used
   - Can be cancelled or limit can be modified
   - Supports setting limits for other players

3. Super Admin Bypass
   - Integration with TotalFreedomMod
   - Super admins can bypass disallowed blocks
   - Note: Block parser hook not yet implemented (requires WorldEdit 7.3.x API)

4. TotalFreedomMod Integration
   - Service provider lookup for super admin checks
   - Graceful degradation if TFM not installed

KEY DIFFERENCES FROM TF-WORLDEDIT
-----------------------------------
1. Architecture:
   - Original: Fork of WorldEdit with modifications in core
   - New: Standalone extension plugin

2. Compatibility:
   - Original: WorldEdit 6.1.7 (Minecraft 1.10)
   - New: WorldEdit 7.3.x (Minecraft 1.21.x)

3. Selection Monitoring:
   - Original: Hooked into LocalSession.dispatchCUIEvent()
   - New: Polls SessionManager every tick (no core modifications needed)

4. Command Interception:
   - Original: Modified GeneralCommands.limit() directly
   - New: Intercepts commands via Bukkit and WorldEdit event systems

5. Block Parser:
   - Original: Modified DefaultBlockParser directly
   - New: Not yet implemented (requires WorldEdit 7.3.x extension API)

TECHNICAL NOTES
---------------
- Uses fully qualified names for org.bukkit.entity.Player to avoid conflicts
  with com.sk89q.worldedit.entity.Player
- Polls for selection changes every tick (may need optimization)
- Command interception uses regex pattern matching
- Event bus registration uses Google Guava EventBus
- Shadow plugin relocates Guava to avoid conflicts
